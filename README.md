# Havaianas — landing page conceito

Landing page conceito inspirada na Havaianas, feita para o portfólio da **Vexo Sites**.
Página leve, em Astro, com animações de rolagem e fotos de produto recortadas por script (`scripts/cutout.mjs`).

> Projeto conceito, não oficial. Sem vínculo com a Havaianas.

## Stack

- Astro
- GSAP (animações e ScrollTrigger)

## Desenvolvido com IA

Construído com o **Claude Code** (Anthropic) como parceiro de desenvolvimento: estrutura, animações, recorte das fotos
e ajustes visuais foram feitos em conversa, com revisão e direção criativa minhas a cada etapa.

## Vídeos

A pasta `video/` tem a gravação da página no monitor (horizontal e vertical) e a versão em reels.

## Rodando localmente

```bash
npm install
npm run dev
```
